# 高中数学竞赛解题方法论

本 skill 是三个数学 Skill 中的**证明核心**，负责「这道题是否真的成立、证明是否闭合」。先判定题目领域与题型（存在/唯一/不存在/极值/计数/证明），再按对应领域挑范式与技巧，写出或审查严谨证明，最后过一遍自检清单。

## 三 Skill 协作协议

按任务选择最小必要链路：

| 任务 | 主 Skill | 协同方式 |
|---|---|---|
| 单题求解、学生过程审查、证明修补 | `math-olympiad` | 默认独立推导；有来源需求或把握不足时再检索 |
| 查同类题、官方解答、出处、方法综述 | `math-olympiad-search` | 只提供证据与候选路线，结论仍由本 skill 独立验证 |
| OCR、批量题库、Atomic/Obsidian、讲义与 PDF | `math-content-pipeline` | 流水线组织材料；非平凡数学内容回交本 skill 审核 |

尊重用户的来源策略：

- `offline` / `断网独立推导`：不得检索，只依题面独立证明；
- `local-only`：需要时调用 `math-olympiad-search`，只查本地资料；
- `web-allowed`：只有用户要求官方来源、联网检索或本地证据不足时才联网。

四个证据层必须分开陈述：

1. **题面层**：题目/OCR/图形是否读对；
2. **来源层**：是否命中可靠出处或标准解；
3. **证明层**：关键推理是否经独立验证；
4. **交付层**：Markdown、Obsidian、TeX、PDF 是否实际生成并渲染检查。

`检索命中` 不等于 `证明成立`，`答案正确` 不等于 `学生原稿完整正确`，`编译成功` 也不等于 `数学审查通过`。

需要向其他 Skill 交接时，至少携带：`task_type`、`source_policy`、完整题面/图形歧义、目标产物，以及 `math_status`（`unverified` / `independently-verified` / `source-matched` / `blocked`）。

单题默认交付：**题干、明确答案、严谨解答、关键方法、边界/等号/退化检查、难度、置信度与待核事项**。学生证明审查还要区分：`答案正确`、`主线正确`、`原稿完整正确`，并指出第一个无效推断和最小修复。

核心哲学（贯穿始终）：**先特殊化、在受限范围化简，再延拓到完整范围**——从 n=1,2,3 或退化情形找规律，再用归纳／夹逼／延拓覆盖全部。

## 一、跨领域通用策略

| 策略 | 适用信号 | 要点 |
|---|---|---|
| 极端原理 | 涉及「最大/最小/最远/最多」的对象 | 取极端元素导出矛盾或结构 |
| 归纳法 | 命题含参数 n，且 n→n+1 有递进结构 | 强归纳/反向归纳/双重归纳/按模分类归纳 |
| 反证法 + 分支矛盾 | 结论为否定、不存在、唯一 | 假设存在→构造特殊值→链式代入→分支逐一矛盾 |
| 鸽巢原理 | 「至少存在」「必有两个…同」 | 抽屉 = 模剩余类/区间/染色类；常配合平均数 |
| 双重计数 | 计数/图论/组合恒等式 | 同一集合两种计数方式列等式 |
| 构造 + 夹逼 | 极值/最值题 | 先证上界（必要性），再构造取等（充分性） |
| 换元/齐次化/对称化 | 条件有对称结构、齐次约束 | 归一化（如令 abc=1）、倒数换元、对称代换 |
| 特殊化 → 延拓 | 多项式/函数方程 | 有限点结论用恒等延拓推广到全定义域 |
| 赋权/势函数/不变量 | 操作题、博弈、递推终止 | 找一个每次操作单调变化的量，或用模不变量定终态 |
| 生成函数/单位根筛选 | 计数、整除性（模 p）、组合恒等式 | $F(x)=\sum a_n x^n$；$\omega=e^{2\pi i/p}$ 处取值筛除 |

## 二、数论

- **整除与模分析**：优先对素数/小模（2,3,4,5,8,9,11,13）取模；$v_p$（p-adic 赋值）估计指数。信号：整除、同余、方程整数解。
- **LTE 升幂引理 / CRT 拆分 / p-adic 分层**：$v_p(a^n\pm b^n)=v_p(a\pm b)+v_p(n)$（p 奇或适当条件下）精确估 p-adic 指数；合数模拆互素因子逐项解再 lcm 合并；按 $p^k$ 分层归纳限解数。信号：含指数的整除、合数模、模 p 计数。
- **无穷下降 / 韦达跳跃**：反设最小解（最小反例/最小度量）→ 造严格更小解 → 矛盾（正整数良序性）；韦达跳跃把整除商识别为新参数、翻转出更小「坏对」。信号：证无正整数解、$D\mid F$ 型整除。
- **平方和表示**：Fermat 两平方和定理（$p\equiv1\pmod4$ ⟺ $p=a^2+b^2$）；Brahmagupta–Fibonacci 恒等式 $(a^2+b^2)(c^2+d^2)=(ac\mp bd)^2+(ad\pm bc)^2$ 提供乘法封闭与多重表示；模 3/模 4 约束排除不可表示数。幂次递推：$N^{2n+1}=(N^n)^2N$。
- **丢番图方程**：因式分解（如 $ab+bc+ca=abc$ 换元）、$(x-a)(y-b)=k$ 的因子枚举、判别式为完全平方、互素性分离。信号：$\frac1x+\frac1y=\frac1n$ 型（素 n 有 $2n-1$ 对解，等价 $(x-n)(y-n)=n^2$）。
- **素数/质数集合划分**：连续整数互素分解（$\gcd(p,p+1)=1$）、末位排除、判别式 $1+4N$ 完全平方、素因子反向构造。
- **单位根筛选（组合整除）**：题设「任意子集和 $\equiv0\pmod p$」且 p 素数 → 加法分解 $M_{ij}=a_i+b_j$ + 生成函数 $F(x)=(1+\sum x^{b_i})^p$ 在 $\omega$ 处整除。
- **递推 + 周期性**：构造数列 $\{a_n\}$ 递推，模 m 分析周期（$(\mathbb Z/m)^*$ 有限 ⇒ 周期必存在）。信号：铺砌、相邻数字和约束计数。
- **GCD/LCM 与互素分离**：$\gcd$ 分解为互素因子分离（coprime separation）、$v_p(\gcd)$ 控制、互素乘积为平方 ⇒ 各因子为平方。
- **整系数多项式取值约束**：整系数多项式在 k 个不同整数处取同一值 m ⇒ $P(x)-m$ 有 k 个整数根 ⇒ 因式分解，用「k 个不同非零整数乘积的下界」排除取值区间。

## 三、代数与不等式

- **AM-GM / Cauchy–Schwarz / 幂平均**：基础三板斧。幂平均链 $m_r\le m_s$（r<s）在约束固定中间阶时做「链式夹逼」（例：$x^2+y^2=1$ 固定 $m_2$，对 $p<2<q$ 夹出 $x^p+y^p\le 2m_2^p$、$x^q+y^q\ge 2m_2^q$）。
- **竞赛形态不等式**：Cauchy 分式（Engel/Titu）$\sum\frac{u_i^2}{D_i}\ge\frac{(\sum u_i)^2}{\sum D_i}$；排序不等式（同序和最大、逆序和最小）；离散 Jensen $\sum f(x_i)\ge n\,f(\bar x)$（凸 f）；Schur $\sum a^r(a-b)(a-c)\ge0$；Hölder 分数幂 $\sum\frac{x_i^{p+1}}{y_i^p}\ge\frac{(\sum x_i)^{p+1}}{(\sum y_i)^p}$；SOS（显式 $\sum c_iL_i^2\ge0$ 并精刻等号）。
- **齐次化与归一化**：齐次不等式先归一（令 $\sum x=1$ 或 $abc=1$），再消元/放缩；$add$-$one$ 技巧补齐次项；三元对称式用 pqr 降维（$p,q,r$ 对称化消元为单参数）。
- **换元**：倒数换元、$x\mapsto\frac{a}{b}$ 比例换元、对称式换 $(s,p)$ 或 $(p,q,r)$；加 k 技巧（每项加常数把分子化为 $\sum v_i$ 常数）。
- **配方法与平方和**：把距离/长度约束配方为 $d^2=(b-\frac Sb\cot\theta)^2+\frac{S^2}{b^2}$，合并多个约束放缩。
- **行列式形式不等式**：Cauchy=二阶 Gram 非负；Hölder（三列循环结构行列式）；Chebyshev=$\det\begin{pmatrix}\sum a_ib_i&\sum a_i\\\sum b_i&n\end{pmatrix}\ge0$；Newton（$E_k=e_k/\binom nk$ 对数凹）用 $2\times2$ 行列式；Jensen 三点凸性用三阶行列式。
- **层集计数公式**：$\sum y_i^2=\int_0^\infty 2t\cdot\#\{i:y_i\ge t\}\,dt$（把平方和按高度分层二重计数）。
- **韦达方法**（含参方程组/多项式）：$x_1+x_2=-p$、$x_1x_2=q$、$\sum\frac1{x_i}=-\frac pq$、$\sum x_i^2=p^2-2q$、$|x_1-x_2|=\sqrt\Delta$；代换后按参数分类，最后验 $\Delta\ge0$。常见陷阱：忘排除使分母为零的参数、忘验实根、符号错。
- **判别式法**：整数解/有理解问题用 $\Delta$ 为完全平方；含参方程按 $\Delta$ 范围分类数解。
- **放缩与夹逼**：拆项放缩、$2ab\le a^2+b^2$、裂项求和夹逼；「上界 + 构造取等」定极值。

## 四、组合

- **计数三法**：递推（按末步/末位分类）、双射化归（难数集 ↔ 已数集）、双重计数。三阶段：递推建立 → 双射 → 求和闭式（Binet 公式 + 奇偶修正）。
- **图论**：握手引理 $\sum\deg=2e$；树 $n-1$ 边、≥2 悬挂点；Mantel/Turán（无 $K_k\Rightarrow e\le e(T_{k-1,n})$，无三角 $e\le\lfloor n^2/4\rfloor$）；Ore（$d(u)+d(v)\ge n$ ⟹ Hamilton 圈）；Brooks；Euler $v-e+f=2$、简单平面图 $e\le3v-6$、$K_5,K_{3,3}$ 非平面；Ramsey $R(3,3)=6$；Cayley $n^{n-2}$；竞赛图（Redei Hamilton 链、强连通 ⟹ Hamilton 圈）。
- **操作/博弈题**：找单调量（势函数，如 $\sum a_i^2$ 每次下降 ⇒ 有限步停）、模不变量（Nim 二进制位和全偶 = 必胜态）、相邻交换归约（局部操作守恒→归约标准形再算）、对应/双射（辗转相除映射到 lcm）、归纳 + 对称（$n=2^k$ 盏灯周期）。信号：有限步/必胜策略/终止性。
- **概率方法 / 期望**：证 $E[g]<0$ 且 $g\ge0$（点态）⟹ 存在使 $g=0$ 的构型；存在性证明 + 计数下界。随机游走/随机过程期望用**零增量分解**（非零差分单步期望不变、零差分时贡献 +1，把全局期望拆成逐步贡献）、**差分方程生成函数**（把绝对差嵌入二阶线性递推）、**Wallis 乘积闭式**（固定步数期望化中位项）。
- **染色/赋权/奇偶**：奇偶性是模 2 不变量；按模剩余类染色分抽屉；图鸽巢（m 点 n 边 ⇒ 存在 $\deg\ge\lceil2n/m\rceil$）。**双重鸽巢**：先按一个量（如距离）分层、再在每层按另一量（如颜色）分抽屉；**奇偶性常把「几乎可行」的临界情形变不可行**（偶数下界 + 平均值反证）。
- **构造与极值**：「构造达到 + 夹逼排除 + 下界论证」三段式；用分块/递归/对称构造；欧拉回路下界（连通 + 环互斥 ⇒ $|E|\ge|V|-1+$环数）。
- **三段式存在性范式（组合几何/覆盖）**：双重计数（把总量分摊到指标）+ 奇偶性（局部值限定为偶数）+ 平均值反证（若全非零则总和超界）。**分块 + 反射拼接**：把全局切两半、反射得对称半、拼合截断旧分隔线，实现构造与唯一性。**上下界精确合拢**：反证给下界 + 构造给上界，夹出精确值（必要性充分性两段式）。**端点剥离归纳**：对最长/最边对象反复剥离降规模。
- **Hall 定理/匹配**：集合型问题（SDR、覆盖）转译为匹配语言。

## 五、几何

- **反演变换**：$OP\cdot OP'=R^2$；距离 $A'B'=\frac{R^2\cdot AB}{OA\cdot OB}$；过心直线↔自身、不过心直线→过心圆、过心圆→直线、不过心圆→圆；共圆⟺共线；保角反向。新圆 $OC'=\frac{R^2OC}{OC^2-r^2}$、$r'=\frac{R^2r}{|OC^2-r^2|}$；与反演圆正交的圆不变。信号：多圆共点、证圆族过定点、共圆共线交替。
- **复数法**：单位圆上设 $\bar a=1/a$；角 $\angle ABC=\arg\frac{a-b}{c-b}$；共线/共圆 ⟺ 交比为实数；垂心 $h=a+b+c$；弧中点 $e^2=bc$；弦 $AB$：$z+ab\bar z=a+b$；切线 $z+a^2\bar z=2a$；垂足 $h=\frac{p+a+b-ab\bar p}{2}$。信号：明显外接圆、垂心/弧中点/垂足/切线、结论是共线共圆垂直。
- **重心坐标**：$P=(x:y:z)$，$\vec P=\frac{x\vec A+y\vec B+z\vec C}{x+y+z}$；内部 $x:y:z=[PBC]:[PCA]:[PAB]$；$G=(1:1:1)$、$I=(a:b:c)$、$O=(\sin2A:\sin2B:\sin2C)$、$H=(\tan A:\tan B:\tan C)$；外接圆 $a^2yz+b^2zx+c^2xy=0$；三点共线 ⟺ 行列式为 0；Ceva 是其直接推论。信号：共点/共线/边比例/切点。
- **笛沙格对合**：完全四边形被直线截出的三组对点与过四点的圆锥曲线交点组，是同一对合的四组对应点；退化含切线。信号：完全四边形 + 直线/线束 + 共圆共线纠缠。
- **圆幂/相似/正弦/坐标化**：圆幂 $SP\cdot SQ$ 定值 + AM-GM 求最值；相似乘积消去中间量；平行线相似化（比例参数 $\sum k_i=1$）；圆内角判别点内外；正弦化线段比；余切坐标化 $\cot\angle$=横差/竖距；梅氏切点消元（切点等长约去动圆参数）。
- **射影定理/面积法/三角**：直角条件翻译为乘积等式；面积 $S\le\frac12 AC\cdot BD$；$\cot\beta+\cot\gamma$ 形式的面积公式。
- **几何不等式**：退化情形判别（平行四边形/梯形一步结案）→ 外包三角形放缩 → 配方法距离上界 → AM-GM 收尾。

## 六、函数方程与序列

- **函数方程总框架**：判定结论形态（存在/唯一/不存在）；用满射（任意值可锚定 $f(\lambda)=c$）、单射（$f(x_1)=f(x_2)\Rightarrow x_1=x_2$）、特殊值代入启动。
- **单双射推导 / 差分改写 / Cauchy 仿射**：代特殊值（如 $y=0$）得 $f\circ f=\mathrm{id}$ ⟹ 双射；交换变量相减消对称部分降一元；整数域用辅助函数 + 比例 + 欧拉桥证 $f$ 仿射（$f(n+td)=f(n)+\alpha td$）。
- **不动点/迭代法**：构造递推轨 $x_{n+1}$ 使 $f(x_n)=x_n$，由「多项式/函数有限（或特定）不动点」得 $f(x)\equiv x$；交换-迭代-不动点归纳；迭代 + 值域排序 + 双命题联立归纳。
- **次数比较 + 恒等延拓**：比较复合次数对齐 $\deg$，再把有限点成立的等式延拓到全定义域。
- **夹逼法（函数不等式）**：特殊值代入得双向不等式，夹出唯一值；离散夹逼（单射 → 基础穷举 → 正向归纳）。
- **不存在性四步模板**：① 反证假设 + 写明全部条件；② 用满射/单射/连续性构造特殊值；③ 链式代入/递推构造 $f^n(x)$；④ 分支逐一矛盾。
- **序列/级数**：裂项求和 $\frac1{n(n+1)}=\frac1n-\frac1{n+1}$；裂项乘积 $\frac{b_{n+1}}{b_n}$；Abel 求和（离散分部积分）$\sum a_mx_m=\sum(\text{累积和})(\text{差分})$；复数根递推（特征根 + 特解 + 共轭三角化）；辅助序列（构造同构递推证整除）；Chebyshev 递推解 Pell $p^2-Dq^2=1$；Cassini 模拟式 $a_na_{n+2}=a_{n+1}^2+C$。
- **递推放缩**：反向代入得第一层不变量；变量对齐后倍增结构迫使退化为常值；交替递推夹逼极限；差分降阶 + 整除（$c^k\mid D$ 恒成立 ⇒ $D=0$）证周期。

## 七、标准范式模板

**三大元范式**（覆盖绝大多数题）：

1. **下降-终止范式**：取「最小反例/最小度量」→ 证明能构造严格更小 → 矛盾。根基是正整数良序性；代表：无穷下降、韦达跳跃、有界单调整数序列终止、差分降阶。信号：整数结构 + 可定义严格减小的量。
2. **守恒-归约范式**：不变量（模/奇偶/2-adic）证不可达、单调量证终止、相邻交换把任意构型归约到标准形再算；双重计数/鸽巢/生成函数同属「换视角计数」。信号：操作/变换/动态过程。
3. **跨域桥接范式**：把题翻译到另一领域再解——几何→代数（圆幂→AM-GM、余切/正弦→代数式、平行线相似→比例参数）、代数→数论（等差求和→整除枚举）、组合→代数（生成函数系数比较）、计数→概率（期望）。信号：同一关系可被两种语言表达。

**具体三段式**：

4. **三段式（存在性/计数）**：构造下界 → 整除/约束排除 → 枚举收尾。
5. **构造达到 + 夹逼排除 + 下界论证（极值）**：必要性（上界）→ 充分性（构造取等）。
6. **分支限界查询（博弈/查询）**：预查小集合（如小质数）→ 按回答模式分支 → 控制每支候选规模。
7. **韦达三段式**：特殊值排除 → 韦达展开化简 → 判别式验证。

## 八、严谨性自检清单（交卷前必过）

1. 等号条件、边界情形、退化情形是否写清？
2. 除以变量前是否排除了零？乘公因子前是否验了分母非零？

7. 对不牢靠的步骤标 ⚠️ 并说明，绝不伪装确定。
8. 给方法起一个可复用的名字，沉淀为范式而非一次性解。

## 十、黄金范例题（输出风格锚点）

下面两题是标准输出范式的样板：**题目 → 答案 → 解答（下界/上界/分情形，编号闭合）→ 关键方法（命名）→ 难度与置信度**。照此风格作答。

### 例题 1：CMO 2023 #1（数论·查询博弈）

**题目**：William 想一个 $1\sim50$ 的整数。Victor 每次挑一个正整数 $m$ 问「$m$ 整除你的数吗？」，如实回答。问 Victor 保证确定答案的最少问题数。

**答案**：$\boxed{15}$。

**解答**：
- **下界（$\ge 15$）**：$1\sim50$ 内质数共 $15$ 个。若只问 $14$ 次，William 采用「除了 $m=1$ 都答否」的对抗策略——该回答序列同时与秘密数 $1$ 和某个从未被问到的质数 $p$ 一致，故无法区分 $1$ 与 $p$。$14$ 次不够。
- **上界（$\le 15$）**：先问 $2,3,5,7$，再分四支：① 全否 → $N=1$ 或 $N\in\{11,13,\dots,47\}$ 共 $12$ 候选，逐一问 $11$ 次；② 仅 $2\mid N$ → 候选 $\{2,4,8,16,22,26,32,34,38,44,46\}$ 共 $11$ 个，逐一问；③ 仅 $3\mid N$ → 候选 $5$ 个；④ 其余 → 设被整除的数之积为 $k\ge5$，$[1,50]$ 中 $k$ 的倍数至多 $10$ 个。总计 $4+\max(11,11,5,10)=15$。

**关键方法**：**质数计数下界 + 分支限界构造**。下界用 $\pi(N-1)$ 作不可区分性论证；上界预查小质数后按回答模式分支、控制每支候选规模。

**难度与置信度**：medium（3.00），0.95。

### 例题 2：Austria 2010 #5（组合·计数）

**题目**：把 $2010\times2010$ 正方形分成三个边长均为整数的矩形，使其中一个面积等于另两个面积的算术平均；本质不同（不能重排得到）的分法数。

**答案**：$\boxed{1678}$。

**解答**（构型分类 → 条件化简 → 整除级联 → 去重）：
- **情形 1（三条平行带）**：中间带 $w_2=2010/3=670$，最小带宽 $w_1\in[1,670]$，共 $670$ 种。
- **情形 2（竖条为 $B$）**：$B=670\times2010$，另两块拼 $1340\times2010$，较短边 $\in[1,1005]$，共 $1005$ 种。
- **情形 3（条带为 $A$ 或 $C$）**：由 $67^2\mid 670\cdot2010$ 且 $67^2>2010$ 得 $a,b$ 均被 $67$ 整除；设 $a=67c,b=67d$ 得 $(30-c)d=300$、$d<30$，$(10,30)$ 内 $300$ 的约数 $\{12,15,20,25\}$，去重 $a=670$ 后新增 $3$ 种。
- **合计**：$670+1005+3=1678$。

**关键方法**：**构型分类 + 整除性级联 + 区间约数枚举 + 去重**（$2010=2\cdot3\cdot5\cdot67$，$67^2>2010$ 是级联触发点）。

**难度与置信度**：medium（3.00），0.90。

> 两题共同示范：极值/计数题先分类再分别闭合，最后去重收尾；每一步编号、结论 $\boxed{}$ 框出、方法命名、难度与置信度落款。
