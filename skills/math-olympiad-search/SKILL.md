# 数学竞赛本地检索

## 角色

本技能只负责“找到并组织可复核证据”。它不因为命中一份解答就宣布证明正确，也不替代 `math-olympiad` 的独立推导。

## 先确定证据策略

- `offline`：不得检索；立即把任务交回独立证明。
- `local-only`：只查已配置的本地语料，不访问网络。
- `web-allowed`：先查本地；本地不足时才允许网络，并明确标注来源边界。

若用户没有说明，涉及私有材料时默认 `local-only`；一般求解默认先独立推理，只有确有必要时再检索。

## 配置

优先读取仓库附近的 `config/local-paths.yaml`，其次读取环境变量：

| 用途 | 配置键 | 环境变量 |
| --- | --- | --- |
| 综合竞赛知识库 | `corpora.general_wiki` | `MATH_OLYMPIAD_GENERAL_WIKI` |
| Obsidian References | `corpora.references` | `MATH_OLYMPIAD_REFERENCES` |
| 组合专题知识库 | `corpora.combinatorics_wiki` | `MATH_OLYMPIAD_COMBINATORICS_WIKI` |

路径不存在时，报告具体缺失项，然后继续能够完成的独立推理；不得猜测目录、伪造命中或把网络结果说成本地结果。

## 检索顺序

1. **固定题干**：先确认变量、范围、量词、图形关系和结论。
2. **方法优先**：先查方法、定理、结构特征，再查整道题。
3. **文件名优先**：先缩小候选文件，再做正文检索。
4. **精确短语**：含 LaTeX 的表达式优先选择有区分度的固定短语，使用固定字符串检索。
5. **小片段阅读**：只打开命中附近的必要上下文，避免一次加载整库。
6. **逐项比对**：比较题干、年份、编号、假设、结论和符号，防止相似题误匹配。
7. **形成证据包**：给出路径、命中片段、匹配理由、差异和可信度。
8. **交回证明**：由 `math-olympiad` 独立验证关键步骤和边界情形。

## 命令模板

```bash
rg --files "$MATH_OLYMPIAD_GENERAL_WIKI" | rg '关键词|年份|编号'
```

```bash
rg -n -F '有区分度的固定短语' "$MATH_OLYMPIAD_REFERENCES"
```

组合题应同时检索综合语料和组合专题语料，避免只查一个库。

## 输出格式

```markdown
## 检索结论
- 证据策略：local-only
- 匹配状态：精确匹配 / 高度相似 / 未确认
- 可信度：高 / 中 / 低

## 证据
- 文件：`绝对路径或用户可访问路径`
- 位置：页码、标题或行号
- 命中：必要的短片段
- 匹配理由：题干与结论的逐项比较
- 差异：符号、范围、条件或版本差异

## 交接
- 可复用方法：...
- 仍需独立验证：...
```

## 纪律

- 不从文件名、OCR 相似度或单个公式直接推断“官方解答”。
- 不大段复制受版权保护的材料；只摘取验证所需片段并以自己的语言总结。
- 不写回本地知识库，除非用户明确要求。
- 不泄露本地目录、学生数据或私有题库内容到公开产物。
